# CX25840 registers written by the Windows driver with AUDIO CAPTURE ENABLED
#
# Captured 2026-08-23 with usbmon on the host while VirtualDub ran in a WinXP
# VM with an audio capture pin open. The project's main session,
# full-session-replay.txt, was recorded with VirtualDub previewing VIDEO ONLY,
# so it contains no audio-path setup at all -- which is why our captures were
# silent for a day.
#
# Only short register writes (opcode 0x08 to slave 0x44, count <= 6) are listed;
# the 59-byte writes to 0x0802 are the audio microcode download and are already
# understood.
#
# "NEW" marks a register the video-only session never writes.
#
# The whole of the audio fix is the first four lines: 0x0104-0x0107, AFE_CTRL.
# Bits 7 and 8 are VGA_SEL_CH2/VGA_SEL_CH3, which choose whether the analogue
# channels carry video or audio. Left at reset, the audio ADC is connected to
# nothing -- it runs, it is clocked, and it digitises silence.
